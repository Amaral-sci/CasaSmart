

# 🏠 CasaSmart

Aplicativo iOS de automação residencial desenvolvido em **SwiftUI**, com foco no gerenciamento e controle de dispositivos inteligentes.

O projeto busca trazer uma experiência semelhante ao aplicativo **Casa da Apple**, permitindo organizar ambientes, visualizar dispositivos e controlar equipamentos inteligentes através de uma interface moderna e intuitiva.

---

## 📱 Sobre o projeto

O CasaSmart é um aplicativo desenvolvido para explorar o desenvolvimento de soluções IoT dentro do ecossistema Apple.

O projeto utiliza tecnologias nativas do iOS para criar uma experiência de automação residencial, unindo interface moderna, organização de dispositivos e comunicação em rede local.

---

## 🚀 Tecnologias utilizadas

- Swift 6
- SwiftUI 6
- Xcode
- MVVM Architecture
- SwiftData
- Network Framework
- TCP/IP Communication
- IoT
- Git/GitHub

---

## ✨ Funcionalidades

### 🏠 Gerenciamento de ambientes

- Organização de dispositivos por cômodos.
- Visualização de ambientes da residência.
- Interface inspirada no aplicativo Casa da Apple.

### 💡 Controle de dispositivos

- Cadastro de dispositivos inteligentes.
- Controle de status dos equipamentos.
- Interface com feedback visual de funcionamento.

### 📡 Comunicação IoT

- Scanner de rede local.
- Identificação de dispositivos conectados.
- Comunicação utilizando protocolo Tuya LAN.
- Controle através de conexão TCP/IP.

---

## 🏗 Arquitetura

O projeto utiliza arquitetura **MVVM (Model-View-ViewModel)** buscando:

- Separação de responsabilidades.
- Código mais organizado e escalável.
- Facilidade de manutenção.
- Melhor gerenciamento de estados.
